Запуск коллекций Postman API
В проекте есть готовые коллекции запросов в формате Postman для API контроллеров:

- CompanyController API — коллекция запросов для работы с компаниями (CompanyController.postman_collection.json)
- UserController API — коллекция запросов для работы с пользователями (UserController.postman_collection.json)

Как использовать коллекции:
Найдите их в корне проекта с расширением .json.

Откройте Postman.

Импортируйте коллекции:

1. Нажмите Import.

2. Выберите файлы JSON коллекций CompanyController.postman_collection.json и UserController.postman_collection.json.

3. Перейдите к созданным коллекциям в Postman, выберите необходимый запрос и нажмите Send.
